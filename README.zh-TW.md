## 系統功能

- **伊斯蘭教法許可性審查**：雇主的業務及你的具體職位——附有經過核驗的《古蘭經》經文、聖訓和教法判例引用；系統只呈現學者觀點，絕不自行發布教法判決（法特瓦）
- **壓迫監察名單核查**：巴勒斯坦 · 維吾爾人 · 喀什米爾 · 羅興亞人（每 2 天更新）
- **完整職涯評估**：履歷匹配、有來源的薪資分析、客製化履歷與求職信
- **面試準備**，包括宗教需求：禮拜、主麻、齋月

**已支援你的語言**：用中文提問即可得到中文回答；《古蘭經》與聖訓均來自經過核驗的中文譯本——宗教文本絕不使用機器翻譯。
