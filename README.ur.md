## 🚧 ترجمہ جاری ہے

یہ فائل اردو میں ترجمہ کی جا رہی ہے۔ اس وقت کے لیے، براہ کرم مکمل انگریزی ورژن پڑھیں:

### 📖 مکمل ورژن پڑھیں
- **[مکمل انگریزی ورژن](README.md)** ← براہ کرم یہ لنک استعمال کریں

### 🤝 ترجمہ میں مدد دینا چاہتے ہیں؟

ہم آپ کی شراکت کا استقبال کرتے ہیں! آپ یہ کر سکتے ہیں:

1. **README.md کو اردو میں ترجمہ کریں**
   - `README.md` → `README.ur.md` نقل کریں
   - محفوظ رکھیں:
     - تمام قرآنی آیات (سورہ اور آیت نمبر کے ساتھ)
     - تمام احادیث کے حوالہ جات (مجموعے اور نمبر کے ساتھ)
     - تمام لنکس اور فارمیٹنگ
     - قانونی مسترد کرنے کا بیان

2. **ایک پل ریکوئسٹ (Pull Request) کھولیں** ترجمہ شدہ فائل کے ساتھ

اللہ آپ کی شراکت کے لیے آپ کو خیر دے!
