# Halal-Career — حلال ملازمتیں، تصدیق شدہ

[🇬🇧 مکمل انگریزی نسخہ](README.md) · [🌍 تمام زبانیں](README.md#languages)

> **یہ دیکھنے سے پہلے کہ ملازمت آپ کی سی وی سے میل کھاتی ہے، یہ دیکھیں کہ آیا وہ حلال ہے۔**

**🚧 یہ ترجمہ زیرِ تکمیل ہے — فی الحال براہِ کرم [مکمل انگریزی نسخہ](README.md) پڑھیں۔**

## یہ کیا کرتا ہے

- **شرعی جواز کی جانچ**: آجر کا کاروبار اور خاص طور پر آپ کا کردار — تصدیق شدہ قرآنی آیات، احادیث اور فتاویٰ کے حوالوں کے ساتھ؛ یہ علماء کے اقوال پیش کرتا ہے، خود فتویٰ جاری نہیں کرتا
- **مظالم کی نگرانی فہرستوں کی جانچ**: فلسطین · اویغور · کشمیر · روہنگیا (ہر 2 دن بعد اپ ڈیٹ)
- **مکمل کیریئر تشخیص**: سی وی میچ، باحوالہ تنخواہ کا تجزیہ، مخصوص سی وی اور کور لیٹر
- **انٹرویو کی تیاری** بشمول دینی ضروریات: نماز، جمعہ، رمضان

**یہ پہلے ہی آپ کی زبان میں کام کرتا ہے**: اردو میں لکھیں، اردو میں جواب ملے گا؛ قرآن و حدیث تصدیق شدہ اردو تراجم سے پیش کیے جاتے ہیں (قرآن: مولانا جوناگڑھی) — شرعی نصوص کا مشینی ترجمہ کبھی نہیں ہوتا۔
