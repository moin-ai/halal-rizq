## Что делает система

- **Проверка дозволенности по шариату**: бизнес работодателя и конкретно ваша роль — с проверенными цитатами из Корана, хадисов и фетв; система излагает мнения учёных и никогда не выносит фетвы сама
- **Проверка по спискам мониторинга угнетения**: Палестина · Уйгуры · Кашмир · Рохинджа (обновляются каждые 2 дня)
- **Полная карьерная оценка**: соответствие резюме, анализ зарплаты с источниками, персонализированные резюме и сопроводительное письмо
- **Подготовка к собеседованию**, включая религиозные потребности: намаз, джума, Рамадан

**Уже работает на вашем языке**: пишите по-русски — ответ будет по-русски; Коран и хадисы берутся из проверенных переводов — религиозные тексты никогда не переводятся машинно.

## Помогите с переводом

Скопируйте `README.md` → `README.ru.md`, переведите добросовестно (сохраняя каждую цитату с точной нумерацией, все ссылки и дисклеймер), затем откройте Pull Request. Да вознаградит вас Аллах.
