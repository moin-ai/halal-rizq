## システムの機能

- **イスラム法上の合法性チェック**：雇用主の事業とあなたの具体的な職務を、検証済みのクルアーンの節・ハディース・ファトワの引用とともに審査。システムは学者の見解を提示するのみで、自らファトワを発することは決してありません
- **抑圧監視リストの照合**：パレスチナ · ウイグル · カシミール · ロヒンギャ（2日ごとに更新）
- **完全なキャリア評価**：履歴書のマッチング、出典つき給与分析、カスタマイズされた履歴書とカバーレター
- **面接準備**：宗教上のニーズ（礼拝、金曜礼拝、ラマダン）への配慮を含む

**すでにあなたの言語で動作します**：日本語で書けば日本語で回答されます。クルアーンとハディースは検証済みの日本語訳（クルアーン：サイード佐藤訳）から提供され、宗教テキストが機械翻訳されることは決してありません。
