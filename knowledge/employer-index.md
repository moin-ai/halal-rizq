## Maintenance rules

1. **Every gate evaluation updates this file** — new row or refreshed date/verdict on the existing row.
2. Rows sourced from watchlists inherit the watchlist's update cycle (2-day routine).
3. Never add a row without evidence link + confidence. Company denials get noted, not erased.
4. Companies here are employers-as-entities; a specific ROLE can change the verdict either way — the gate always runs per-JD.
