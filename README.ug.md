## 🚧 تەرجىمە جاريدۇ

بۇ ھۆججەت ئۇيغۇرچىسىگە تەرجىمە قىلىنماقتا. ئامالىيەتتە، تولۇق ئىنگلىزچە نۇسخىسىنى ئوقۇڭ:

### 📖 تولۇق نۇسخىنى ئوقۇڭ
- **[تولۇق ئىنگلىزچە نۇسخىسى](README.md)** ← بۇ باغلىنتىنى ئىشلىتىڭ

### 🤝 تەرجىمىسىگە ياردەم بەرمەكچىسىز؟

بىز سىزنىڭ كۆمەكتىشىنى قارشى ئالىمىز! سىز شۇنىڭدىن:

1. **README.md نى ئۇيغۇرچىسىگە تەرجىمە قىلىڭ**
   - `README.md` → `README.ug.md` كۆچۈرۈڭ
   - مۇهىملىدۇرۇڭ:
     - بارلىق قۇرئان ئايەتلىرى (سۈرە ۋە ئايەت نومۇرى بىلەن)
     - بارلىق حەدىس مەۋجۇدى (جەمئىيە ۋە نومۇرى بىلەن)
     - بارلىق باغلىنتىلار ۋە فورماتتاش
     - قانۇنى ئىنكار قىلىش بەيانى

2. **تەرجىمە قىلىنغان ھۆججەت بىلەن پۇل تېلىقى (Pull Request) ئاچىڭ**

سىزنىڭ كۆمەكتىشىڭىز ئۈچۈن ئالله سىزنى ياخشى جازالاسۇن!
