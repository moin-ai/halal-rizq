# Halal-Rizq — ھالال خىزمەتلەر، دەلىللەنگەن

**🚧 بۇ تەرجىمە تېخى تاماملانمىدى — ھازىرچە [تولۇق ئىنگلىزچە نۇسخىنى](README.md) ئوقۇڭ.**

## بۇ سىستېما نېمە قىلىدۇ

- **شەرئىي جائىزلىقنى تەكشۈرۈش**: خوجايىننىڭ تىجارىتى ۋە سىزنىڭ خىزمىتىڭىز — دەلىللەنگەن قۇرئان ئايەتلىرى، ھەدىسلەر ۋە پەتىۋالار بىلەن؛ سىستېما ئۆلىمالارنىڭ قاراشلىرىنى كۆرسىتىدۇ، ئۆزى پەتىۋا چىقارمايدۇ
- **زۇلۇم كۆزىتىش تىزىملىكلىرى**: پەلەستىن · ئۇيغۇرلار · كەشمىر · روھىنگيا
- **تولۇق كەسپىي باھالاش**: CV ماسلىشىشى، مائاش تەھلىلى، خاس CV ۋە خەت
- **سۆھبەتكە تەييارلىق** — دىنىي ئېھتىياجلار بىلەن: ناماز، جۈمە، رامىزان

**سىستېما ھازىرلا تىلىڭىزدا ئىشلەيدۇ**: ئۇيغۇرچە يېزىڭ، ئۇيغۇرچە جاۋاب ئالىسىز؛ قۇرئان دەلىللەنگەن ئۇيغۇرچە تەرجىمىدىن (مۇھەممەد سالىھ) كېلىدۇ — دىنىي تېكىستلەر ھەرگىز ماشىنا تەرجىمىسى ئەمەس.
