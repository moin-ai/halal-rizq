# Halal-Career — งานฮาลาล ผ่านการตรวจสอบ

[🇬🇧 ฉบับภาษาอังกฤษฉบับเต็ม](README.md) · [🌍 ทุกภาษา](README.md#languages)

> **ตรวจสอบว่างานนั้นฮาลาลหรือไม่ ก่อนที่จะตรวจสอบว่ามันเหมาะกับเรซูเม่ของคุณ**

**🚧 การแปลนี้กำลังดำเนินการ — ตอนนี้โปรดอ่าน[ฉบับภาษาอังกฤษฉบับเต็ม](README.md)**

## ระบบทำอะไรบ้าง

- **ตรวจสอบความถูกต้องตามหลักศาสนาอิสลาม**: ธุรกิจของนายจ้างและบทบาทเฉพาะของคุณ — พร้อมการอ้างอิงอัลกุรอาน หะดีษ และฟัตวาที่ผ่านการตรวจสอบ ระบบนำเสนอทัศนะของอุละมาอ์เท่านั้น ไม่เคยออกฟัตวาเอง
- **ตรวจสอบรายชื่อเฝ้าระวังการกดขี่**: ปาเลสไตน์ · อุยกูร์ · แคชเมียร์ · โรฮิงญา (อัปเดตทุก 2 วัน)
- **การประเมินอาชีพแบบครบถ้วน**: การจับคู่เรซูเม่ การวิเคราะห์เงินเดือนพร้อมแหล่งอ้างอิง เรซูเม่และจดหมายสมัครงานที่ปรับแต่งเฉพาะ
- **การเตรียมสัมภาษณ์** รวมถึงความต้องการทางศาสนา: การละหมาด ละหมาดวันศุกร์ เดือนรอมฎอน

**ใช้งานในภาษาของคุณได้แล้ว**: เขียนเป็นภาษาไทย ระบบจะตอบเป็นภาษาไทย อัลกุรอานและหะดีษมาจากคำแปลที่ผ่านการตรวจสอบ — ข้อความทางศาสนาไม่เคยใช้การแปลด้วยเครื่อง
