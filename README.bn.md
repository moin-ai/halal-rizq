আমরা আপনার অবদান স্বাগত জানাই! আপনি পারেন:

1. **README.md কে বাংলায় অনুবাদ করুন**
   - `README.md` → `README.bn.md` অনুলিপি করুন

     - সব কুরআনের আয়াত (সূরা এবং আয়াত নম্বর সহ)
     - সব হাদিসের রেফারেন্স (সংগ্রহ এবং নম্বর সহ)
     - সব লিংক এবং ফরম্যাটিং
     - দায়িত্বমুক্তির বিবৃতি

2. **একটি পুল রিকোয়েস্ট (Pull Request) খুলুন** অনুবাদকৃত ফাইল সহ
