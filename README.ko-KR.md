**🚧 이 번역은 진행 중입니다 — 지금은 [완전한 영어 버전](README.md)을 읽어 주세요.**

## 시스템 기능

- **이슬람 율법상 허용 여부 검사**: 고용주의 사업과 당신의 구체적인 직무를 검증된 꾸란 구절·하디스·파트와 인용과 함께 심사합니다. 시스템은 학자들의 견해를 제시할 뿐, 스스로 파트와를 내리지 않습니다
- **억압 감시 목록 대조**: 팔레스타인 · 위구르 · 카슈미르 · 로힝야 (2일마다 업데이트)
- **완전한 커리어 평가**: 이력서 매칭, 출처가 있는 급여 분석, 맞춤형 이력서와 커버레터
- **면접 준비**: 종교적 필요(예배, 금요 예배, 라마단) 포함

**이미 당신의 언어로 작동합니다**: 한국어로 쓰면 한국어로 답합니다. 꾸란과 하디스는 검증된 한국어 번역(꾸란: 하메드 최 역)에서 제공되며, 종교 텍스트는 절대 기계 번역되지 않습니다.
