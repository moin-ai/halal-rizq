## 系统功能

- **伊斯兰教法许可性审查**：雇主的业务及你的具体职位——附有经过核验的《古兰经》经文、圣训和教法判例引用；系统只呈现学者观点，绝不自行发布教法判决（法特瓦）
- **压迫监察名单核查**：巴勒斯坦 · 维吾尔人 · 克什米尔 · 罗兴亚人（每 2 天更新）
- **完整职业评估**：简历匹配、有来源的薪资分析、定制简历与求职信
- **面试准备**，包括宗教需求：礼拜、主麻、斋月

**已支持你的语言**：用中文提问即可得到中文回答；《古兰经》与圣训均来自经过核验的中文译本（《古兰经》：马坚译本）——宗教文本绝不使用机器翻译。
